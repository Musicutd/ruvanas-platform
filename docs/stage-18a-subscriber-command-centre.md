# Stage 18A — Subscriber Command Centre

Stage 18A turns the subscriber dashboard into a clearer daily operating home for retail, school and online-radio customers. It changes presentation and guidance only; it does not weaken permissions, alter entitlements, create new billing behaviour or expose unavailable products.

## Subscriber experience

- A prominent next-action card explains the first task that needs attention and shows real setup progress.
- A service pulse summarises availability, plan, live streams and prepared players without technical infrastructure language.
- Quick actions provide direct access to the subscriber's most common permitted tools.
- Usage cards show player, live-stream and storage consumption with accessible progress meters.
- The complete tool set remains grouped by task for less frequent work.
- Help and support are visible in the top navigation and contextual help remains available below the operating tools.
- Retail-specific wording is replaced with neutral location and player language so the same portal works for schools and online-radio customers.

## Access and safety

- Quick actions are selected only from the already entitlement-filtered subscriber navigation.
- Existing organisation membership, product entitlement and route-level permission checks remain authoritative.
- Setup completion continues to use real station, schedule, player and playback evidence.
- No administration controls or unavailable products are added to subscriber navigation.

## Verification

- Automated application tests cover subscriber navigation and onboarding behaviour.
- Static checks cover the command-centre accessibility markers and responsive breakpoint.
- The complete test suite, static integrity checks and production build must pass before publication.
